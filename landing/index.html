DevDocs is a real-time collaborative document editor you can run yourself. Write together, comment, diagram, and keep full control of your data.

Get started View on GitHub

Everything you expect from a modern doc tool

Built on Yjs, Tiptap and Supabase. No vendor lock-in.

👥

Real-time collaboration

Multiple people editing the same document live, with presence cursors. CRDT-backed, so no lost edits.

💬

Inline comments

Select text, start a thread, reply, and archive when resolved. Click any highlight to reopen the discussion.

🕑

Version history

Snapshot a document and restore any earlier version. A true revert, not just a diff view.

🖼️

Images

Drag, drop or paste screenshots. Stored in object storage so documents stay fast and lightweight.

📊

Mermaid diagrams

Write mermaid syntax and get live-rendered flowcharts, sequence diagrams and more, right in the doc.

🔐

Sharing & permissions

Share by email with view, edit or manage roles, enforced end to end by row-level security.

Ready when you are

Sign in and start writing. Your team, your server, your data.
